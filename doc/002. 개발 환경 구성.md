# 002. 개발 환경 구성

## requirement

- python
- git
- visual studio code
- ESP-IDF : Visual studio code Espressif
- [EIM (ESP-IDF Installation Manager)](https://docs.espressif.com/projects/idf-im-ui/en/latest/)
- toolchain version: v6.0.1
- [udev setting (linux only)](https://docs.espressif.com/projects/esp-idf/en/v6.0.1/esp32p4/api-guides/dfu.html)
- For Linux, run this command to update your permissions for serial port access
  - `sudo usermod -aG dialout $USER`

## hello world

- for windows
  - 터미널에서 ESP-IDF 프로파일 실행

```shell
xcopy /e /i $env:IDF_PATH\examples\get-started\hello_world 000.hello_world
idf.py set-target esp32p4
idf.py menuconfig
idf.py flush
idf.py monitor
```

- for linux

```shell
source "~/.espressif/tools/activate_idf*.sh"
cp -r $IDF_PATH/examples/get-started/hello_world 000.hello_world
idf.py set-target esp32p4
idf.py menuconfig
idf.py flush
idf.py monitor
```

## debug for VS Code

1. Ctrl+P : `ESP-IDF: Select Port to Use`
2. Ctrl+P : `ESP-IDF: Select OpenOCD Board Configuration` : `esp32p4 (via buildin USB-JTAG)
3. launch.json 작성

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "gdbtarget",
      "request": "attach",
      "name": "Eclipse CDT GDB Adapter"
    },
    {
      "type": "espidf",
      "name": "Launch",
      "request": "launch"
    }
  ]
}
```

## Chip Revision 문제

- TAP5 의 chip revision이 1.3 우회
- menu config
  - `idf.py menuconfig`
  - [x] `Component config` -> `Hardware Settings` -> `Chip revision` -> `Select ESP32-P4 revision < 3.0`
