1. 이미지 파일과 한글 폰트를 이용해 디스플레이 이미지, 텍스트 출력

## create project

```shell
idf.py create-project 001.hello-world-lvgl
idf.py set-target esp32p4
idf.py add-dependency espressif/m5stack_tab5
idf.py menuconfig
idf.py save-defconfig
idf.py clean
idf.py flash
idf.py monitor
idf.py flash monitor
```

## 한글 폰트

- 범위 : 0x20-0x7F, 0x00A0-0x00FF, 0x2190-0x21FF, 0x25A0-0x25FF, 0x3130-0x318F
- 0x20-0x7F (기본 ASCII): 영어 대소문자, 숫자, 그리고 기본 기호
- 0x00A0-0x00FF (Latin-1 Supplement): 디버그 창이나 코드 상에서 종종 쓰이는 라틴 확장 기호 및 단위 기호
- 0x2190-0x21FF (Arrows): 코드 흐름 및 UI에 자주 쓰이는 화살표 기호 집합
- 0x25A0-0x25FF (Geometric Shapes): UI를 구성할 때 유용한 기본 도형 기호
- 0x3130-0x318F (한글호환자모)
