# 000.hello-world-baremetal

> ⚠️ **주의**: 이 문서는 AI에 의해 분석 및 작성된 내용입니다. **빌드가 정상적으로 수행되는 것까지만 확인되었으며, 실제 하드웨어에 플래시(Flash)하여 동작을 테스트하지는 않았으므로 완벽한 동작을 보장하지 않습니다.** 참고용으로만 활용하시기 바랍니다.

이 프로젝트는 **ESP-IDF와 같은 외부 프레임워크나 표준 C 라이브러리를 전혀 사용하지 않고 오직 레지스터 직접 제어만으로 ESP32-P4(RISC-V)를 구동하는 순수 베어메탈(Baremetal) 예제**입니다.

## 파일 구성

* `startup.S`: 부팅 시 가장 먼저 실행되는 어셈블리 코드로, C 런타임 환경(스택 포인터 초기화, BSS 영역 제로 초기화)을 구성하고 `main()` 함수를 호출합니다.
* `main.c`: 하드웨어 제어 로직 및 메인 애플리케이션 코드가 포함된 핵심 파일입니다.

## 주요 동작 방식 (`main.c`)

이 프로젝트의 모든 제어는 인터럽트(Interrupt) 방식이 아닌 상태 레지스터를 지속해서 확인하는 **순수 폴링(Polling) 방식**으로 구현되어 있습니다.

### 1. 표준 라이브러리 대체 구현
* 베어메탈 환경(`-nostdlib` 컴파일 옵션)이므로 C 표준 라이브러리가 포함되지 않습니다.
* **64비트 나눗셈 구현:** ESP32-P4(RV32) 코어는 64비트 하드웨어 나눗셈 연산을 지원하지 않아 GCC 내부 호출용 `__udivdi3`, `__umoddi3` 함수를 비트 시프트 연산으로 직접 구현했습니다.
* **문자열 함수:** `strlen`을 대신할 `my_strlen` 함수를 자체 구현하여 사용합니다.

### 2. 시스템 클럭 및 타이머 설정
* **와치독(WDT) 비활성화:** 시스템이 멈췄다고 판단하여 강제로 칩을 재부팅시키는 메인 와치독(Main WDT)과 저전력 와치독(LP WDT)을 비활성화합니다.
* **타이머 구동:** 글로벌 시스템 타이머(`TIMG1`)를 활성화하고, 하드웨어 타이머 레지스터를 읽어 현재 시간을 가져오는 `get_time_ms()` 함수와 `delay_ms()` 대기 함수를 구현했습니다.

### 3. UART 통신 설정 및 폴링 입출력
* **초기화:** 보드레이트(Baudrate)를 수동으로 계산해 설정하고, IOMUX와 GPIO 매트릭스 레지스터를 직접 조작해 UART1의 TX(17), RX(18) 핀을 설정합니다.
* **송수신 로직:** UART 통신 시 FIFO 레지스터의 상태를 직접 확인하여 공간이 있을 때만 데이터를 송수신하는 가장 원초적인 폴링 방식으로 구현되었습니다.

### 4. 메인 루프 동작
시스템 초기화 후 무한 루프(`while(1)`)를 돌며 다음 동작을 수행합니다.
1. **사용자 입력 대기:** UART 수신 버퍼에 문자가 들어오면 화면에 에코(Echo)를 출력합니다. 만약 입력된 문자가 `'R'` 또는 `'r'`인 경우, 와치독 타이머에 타임아웃을 강제로 유발하여 **하드웨어 리셋을 실행**합니다.
2. **주기적 상태 로그 출력:** 1초(1000ms) 간격으로 현재 시스템 누적 실행 시간과 루프 카운터를 UART 터미널에 출력합니다.

본 예제는 칩의 데이터시트에 명시된 메모리 맵 레지스터 주소에 직접 접근하여 하드웨어를 제어하는 로우레벨(Low-level) 시스템 프로그래밍의 기초를 학습하기 위한 목적으로 작성되었습니다.
